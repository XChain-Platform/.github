# .github

This is the XChain Platform organization repository. It holds two things:

1. **Organization profile** (`profile/README.md`): the page shown on the
   [XChain-Platform](https://github.com/XChain-Platform) organization landing.
2. **Default community-health files** (`SECURITY.md`, `CONTRIBUTING.md`,
   `CODE_OF_CONDUCT.md`): GitHub applies these to any repository in the
   organization that does not provide its own.

Most XChain repositories ship their own tailored `SECURITY.md` and
`CONTRIBUTING.md`; those take precedence over the defaults here. The Code of
Conduct and `MAINTAINERS.md` are not duplicated per repository: the
`CODE_OF_CONDUCT.md` in this repo applies organization-wide via GitHub, and the
canonical Code of Conduct and maintainer list live in the
[`xchain-documentation`](https://github.com/XChain-Platform/xchain-documentation)
repository.

To report a security issue, see `SECURITY.md`. To contribute, see the
`CONTRIBUTING.md` of the specific repository you are working in.
